공간 조인 한 번에 몇십 분씩 기다려 본 적 있으신가요. 레이어가 커질수록 분석 시간은 가파르게 늘어납니다. 이때 가장 먼저 확인할 것이 **QGIS 공간 인덱스**입니다. 만드는 데 몇 초면 되고 효과는 바로 나타납니다.

> **바쁘면 이것만**: 공간 인덱스는 객체의 경계상자를 미리 정리해 둔 목록입니다. 레이어 우클릭 → **속성 → 소스** 탭에서 **공간 인덱스 생성** 버튼을 누르면 끝입니다. 데이터 자체는 하나도 바뀌지 않습니다.

## 공간 인덱스란 무엇인가

공간 인덱스는 각 객체의 **경계상자(bounding box)** 를 트리 구조로 정리해 둔 목록입니다. 흔히 R-tree 계열을 씁니다.

인덱스가 없으면 QGIS는 "이 점이 어느 폴리곤 안에 있나"를 물을 때마다 전체 객체를 하나씩 비교합니다. 객체가 10만 개면 비교도 10만 번입니다.

인덱스가 있으면 **경계상자가 겹치는 후보만** 먼저 추립니다. 정밀한 도형 비교는 후보에만 합니다. 그래서 대용량에서 속도가 크게 오릅니다.

인덱스는 **찾는 방법**만 바꿉니다. 도형도 속성값도 그대로입니다.

## 언제 효과가 있는가

효과가 큰 작업입니다.

- 공간 조인, 클립, 교차, 차집합
- 위치로 객체 선택
- 대용량 레이어를 화면에 그릴 때
- 공간 필터로 범위를 좁힐 때

효과가 없는 쪽도 분명합니다.

- **속성값 필터와 정렬**. 이건 속성 인덱스가 할 일입니다.
- 객체가 몇백 개뿐인 소량 데이터
- 이미 인덱스가 만들어져 있는 레이어

## 셰이프파일은 인덱스가 별도 파일로 생긴다

셰이프파일에서 인덱스는 **파일이 하나 더 생기는** 방식입니다. QGIS와 GDAL이 만드는 것은 `.qix`입니다. Esri 도구로 만들면 `.sbn`과 `.sbx`가 생깁니다.

`.qix`는 `.shp` 옆에 놓입니다. 그러니 **파일을 복사하거나 전달할 때 `.qix`도 같이** 가져가야 인덱스가 유지됩니다. 빠뜨렸어도 받은 쪽에서 다시 만들면 됩니다.

구성 파일 이야기는 [SHP 파일이란](/blog/what-is-shapefile/)에서 정리했습니다.

## 만드는 3단계

### 1단계 — 레이어 하나에 만들기

<!-- 검토: 버튼 위치·비활성 표시는 QGIS 버전에서 확인 후 공개 -->
레이어 우클릭 → **속성 → 소스** 탭으로 들어갑니다. **공간 인덱스 생성** 버튼을 누르면 됩니다. 이미 인덱스가 있으면 버튼이 비활성으로 보입니다.

> 📷 **스크린샷 ①** — 레이어 속성 소스 탭의 공간 인덱스 생성 버튼
> _최종본 alt·캡션: "QGIS 레이어 속성 소스 탭에서 공간 인덱스 생성 버튼을 누르는 화면"_

### 2단계 — 여러 레이어를 한 번에

레이어가 많으면 하나씩 누를 필요가 없습니다. **처리 도구상자 → 벡터 일반 → 공간 인덱스 생성** 을 엽니다. 대화상자에서 **일괄 처리(batch)** 로 전환하면 레이어 목록을 한꺼번에 넣을 수 있습니다.

> 📷 **스크린샷 ②** — 공간 인덱스 생성 알고리즘을 일괄 처리로 실행
> _최종본 alt·캡션: "QGIS 처리 도구상자에서 공간 인덱스 생성을 일괄 처리로 실행하는 화면"_

### 3단계 — 제대로 만들어졌는지 확인

두 가지로 확인합니다. 먼저 폴더를 열어 `.shp` 옆에 `.qix`가 생겼는지 봅니다. 그다음 무거운 공간 조인을 인덱스 전후로 돌려 봅니다. 초를 재지 않아도 체감으로 차이가 납니다.

> 📷 **스크린샷 ③** — 탐색기에서 shp 옆에 생성된 qix 파일 확인
> _최종본 alt·캡션: "탐색기에서 셰이프파일 옆에 생성된 .qix 공간 인덱스 파일을 확인하는 화면"_

## 도형을 편집한 뒤에는

<!-- 검토: 편집 후 .qix 자동 갱신 여부 확인 -->
도형을 많이 추가하거나 지운 뒤에는 인덱스를 **다시 만드는 편이 안전**합니다. 예전 경계상자가 남아 있으면 후보를 잘못 고를 수 있습니다.

PostGIS 같은 데이터베이스는 GiST 인덱스를 따로 만들어 씁니다.

## 흔한 실수와 함정

- **인덱스 없이 대용량 공간 조인부터 돌리기**: 한참 기다린 뒤에야 알게 됩니다. 큰 레이어는 분석 전에 먼저 만드세요.
- **`.qix`를 안 챙기고 복사**: 전달받은 쪽에서 다시 느려집니다.
- **인덱스가 데이터를 바꾼다는 오해**: 도형도 속성도 그대로입니다.
- **속성 필터가 빨라지길 기대**: 공간 인덱스는 위치 질의만 돕습니다.
- **이미 있는데 또 만들기**: 버튼 상태나 폴더의 `.qix`를 먼저 확인하세요.

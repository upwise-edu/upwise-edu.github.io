공공데이터 레이어만 띄워 놓으면 여기가 어디인지 감이 오지 않습니다. 배경에 실제 지도가 깔려야 위치가 읽힙니다. **QGIS 브이월드** 연결은 그 문제를 가장 빠르게 해결하는 방법입니다. 인증키 발급부터 연결까지 한 번에 정리합니다.

> **바쁘면 이것만**: 브이월드 인증키를 발급받아 QGIS의 **XYZ Tiles**에 URL로 등록하면 끝입니다. 플러그인보다 이 방법이 안정적입니다. 인증키는 개인용이니 **깃허브나 블로그에 올리지 마세요.**

## 브이월드란 무엇인가

브이월드(V-World)는 국토교통부가 운영하는 **공간정보 오픈플랫폼**입니다. 고해상도 항공·위성영상, 기본지도, 지적, 행정경계 같은 공공 공간정보를 제공합니다. 국내 데이터 작업의 배경지도로 가장 무난한 선택입니다.

## QGIS에 붙이는 두 가지 방법

1. **XYZ/WMTS 타일 직접 등록** — URL 한 줄을 등록합니다. 플러그인 업데이트에 영향받지 않아 안정적이고, 이 글의 본 실습입니다.
2. **커뮤니티 플러그인 사용** — 플러그인 관리자에서 브이월드 관련 플러그인을 설치하면 클릭만으로 배경지도를 추가할 수 있습니다. 편하지만 플러그인이 관리되지 않으면 동작이 멈출 수 있습니다.

## 연결 4단계

### 1단계 — 인증키 발급

브이월드 사이트(vworld.kr)에 가입한 뒤 **오픈API → 인증키 신청**에서 키를 발급받습니다. 신청할 때 사용 URL을 함께 등록합니다. 발급된 키는 개인용이니 공개된 곳에 올리지 마세요.

> 📷 **스크린샷 ①** — 브이월드 오픈API 인증키 신청 화면
> _최종본 alt·캡션: "브이월드 오픈API 인증키를 신청하는 화면"_

### 2단계 — QGIS에서 새 연결 만들기

QGIS **브라우저 패널**에서 **XYZ Tiles**를 찾아 우클릭 → **새 연결**을 누릅니다. 연결 이름은 알아보기 쉽게 "브이월드 기본지도" 같은 식으로 적습니다.

> 📷 **스크린샷 ②** — 브라우저 패널 XYZ Tiles 우클릭 후 새 연결
> _최종본 alt·캡션: "QGIS 브라우저 패널에서 XYZ Tiles 새 연결을 만드는 화면"_

### 3단계 — 타일 URL 입력

URL 칸에 브이월드 타일 주소를 넣습니다. `<인증키>` 자리에 발급받은 키를 그대로 붙여 넣으세요.

<!-- 검토: 브이월드 타일 URL·레이어명·확장자는 vworld 오픈API 문서에서 최신 형식 확인 후 공개 -->

```
https://api.vworld.kr/req/wmts/1.0.0/<인증키>/Base/{z}/{y}/{x}.png
```

`Base` 자리를 바꾸면 지도 종류가 달라집니다. 일반 지도는 **Base**, 위성영상은 **Satellite**(확장자 jpeg), 도로·지명만 겹쳐 쓰는 레이어는 **Hybrid**입니다.

> 📷 **스크린샷 ③** — XYZ 연결 대화상자에 브이월드 타일 URL 입력
> _최종본 alt·캡션: "QGIS XYZ 연결 대화상자에 브이월드 타일 URL을 입력하는 화면"_

### 4단계 — 지도에 추가하기

브라우저 패널에서 만든 연결을 **더블클릭**하면 지도 창에 배경지도가 깔립니다. 레이어 패널에서 배경지도를 맨 아래로 내리면 공공데이터 레이어가 그 위에 올라옵니다.

> 📷 **스크린샷 ④** — 브이월드 배경 위에 공공데이터 레이어가 올라간 화면
> _최종본 alt·캡션: "QGIS에서 브이월드 배경지도 위에 공공데이터 레이어를 겹쳐 본 화면"_

## 좌표계는 신경 쓰지 않아도 될까

브이월드 타일은 웹 메르카토르(**EPSG:3857**)로 제공됩니다. 프로젝트 좌표계가 5186이나 5179여도 QGIS가 실시간 재투영하므로 그대로 겹쳐 보입니다. 다만 레이어 자체의 좌표계가 잘못 정의돼 있으면 그때는 어긋납니다. 그 경우는 [QGIS 좌표계 문제 해결](/blog/qgis-coordinate-system/)에서 진단하세요.

## 흔한 실수와 함정

- **키 없이 또는 틀린 키로 URL 사용**: 타일이 하나도 뜨지 않습니다. `<인증키>` 자리를 실제 키로 바꿨는지 먼저 확인하세요.
- **http와 https 혼동**: https로 넣는 것이 안전합니다.
- **키 노출**: URL에 키가 그대로 들어가므로, 프로젝트 파일이나 화면 캡처를 공개할 때 가려야 합니다.
- **타일이 안 뜰 때**: 확대 레벨을 조정해 보고, 인증키 만료 여부와 URL 오타를 순서대로 확인합니다.
